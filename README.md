# Week 1 - Lab Setup Project

This repository contains my Week 1 lab setup project for the Cybersecurity Program.

## Lab Setup Steps Completed:
- Installed VMware (instead of VirtualBox) to create the virtual environment.
- Configured a NAT Network with the subnet **10.0.0.0/24**.
- Imported and set up Kali Linux.
- Assigned a static IP to Kali Linux: **10.0.0.2/24**.
- Enabled Shared Folders between the host and Kali Linux.
- Verified full internet access from Kali (Ping 8.8.8.8 successful).
- Took a Snapshot of the virtual machine.
